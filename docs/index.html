How It Works

# Extract structured data from an invoice image from src.extract import extract_invoice result = extract_invoice("invoice.jpg") # → {"vendor": "Acme Corp", "total": "150.00", "date": "2026-01-15", ...}
# Batch process a folder of invoices from src.batch import process_folder process_folder("./invoices/", "output.json") # → processes all images, saves structured JSON

What Gets Extracted

🏢 Vendor

Automatically identifies the company or merchant name from invoice headers.

📅 Dates

Parses invoice date, due date, and payment deadlines across multiple formats.

💰 Totals

Extracts total, subtotal, tax amounts with multi-currency support ($, €, £, ¥).

#️⃣ Invoice #

Identifies invoice, receipt, and reference numbers from standard patterns.

📋 Line Items

Parses descriptions, quantities, unit prices, and line-level totals.

🔧 JSON Output

Clean, structured JSON ready for accounting software, spreadsheets, or databases.
